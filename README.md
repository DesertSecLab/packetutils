# PacketUtils

**Practical Network & Firewall Tools**

[PacketUtils](https://packetutils.com/) provides free online tools and practical guides for networking, firewall configuration, and server administration.

## Features

- **Network & CIDR** — Calculate subnets and work with IP addresses.
- **Firewall Tools** — Generate iptables rules and configure firewall settings.
- **Ports & Services** — Learn about common network ports and their security implications.
- **Cloud Networking** — Find practical guides for network configuration on cloud servers.

## Website

Visit **[https://packetutils.com/](https://packetutils.com/)** to explore the tools and guides.

## Project Goals

PacketUtils aims to make common networking tasks easier with practical, accessible tools and clear technical documentation.

Tools are designed to run directly in the browser wherever applicable, without requiring users to install additional software.
